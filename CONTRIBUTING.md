# Contributing

Thank you for contributing to crawl-skku.

1. Create a focused branch and keep changes scoped to one concern.
2. Run `uv sync --locked`, then run formatting, linting, type checking, and tests from the README.
3. Use synthetic fixtures. Do not add private information or copied full upstream content to tests.
4. Preserve existing public API paths and schemas unless the pull request explicitly documents a versioned breaking change.
5. Describe affected upstream sources and parser fixtures in the pull request.

By contributing, you agree that your contribution is licensed under Apache-2.0.
